# Campaign Service

Campaign management and email automation service for cold outreach.

## Overview

This service handles:
- Campaign creation and management
- Email template management
- Spintax processing for email personalization
- Campaign execution and tracking
- Integration with lead service for prospect data

## Running the Service

### Development
```bash
./gradlew bootRun
```

### Build
```bash
./gradlew build
```

### Run JAR
```bash
java -jar build/libs/campaign-svc-0.0.1-SNAPSHOT.jar
```

## Port

Default port: **8082**

## API Documentation

Swagger UI available at: `http://localhost:8082/swagger`
